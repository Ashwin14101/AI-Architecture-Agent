# CloudStore E-commerce Portal Architecture Documentation
## Project Executive Summary & Creators
The CloudStore E-commerce Portal is a web-based application designed to handle PDF files, extract metadata, and store it in a database. The system consists of multiple logical components, including a PDF File Handler, PDF Processor, Database, and Load Balancer. This documentation outlines the architecture, design, and implementation of the CloudStore E-commerce Portal.

## Functional & Non-Functional Requirements Checklist

## Logical Component Architecture & Patterns Applied
The CloudStore E-commerce Portal consists of the following logical components:
* [COMP-001]: PDF File Handler (Type: web-server): Handles PDF file uploads and sends them to the PDF Processor for metadata extraction.
* [COMP-002]: PDF Processor (Type: web-server): Extracts metadata from PDF files and stores it in the Database.
* [COMP-003]: Database (Type: database): Stores the extracted metadata from PDF files.
* [COMP-004]: Load Balancer (Type: load-balancer): Distributes incoming traffic to the PDF File Handler.

The following patterns have been applied to the architecture:
* Load Balancing: to distribute incoming traffic and ensure high availability.
* Service-Oriented Architecture: to separate concerns and enable scalability.

## Database Design
The CloudStore E-commerce Portal uses a PostgreSQL database with the following tables:
* pdf_files: stores information about the PDF files.
* pdf_metadata: stores the extracted metadata from the PDF files.

The schema relationships between the tables are as follows:
* A PDF file can have multiple metadata entries (one-to-many).
* A metadata entry is associated with one PDF file (many-to-one).

## REST API Specifications & Routing Map
The CloudStore E-commerce Portal provides the following REST endpoints:
* POST /api/pdf: uploads a PDF file and sends it to the PDF Processor for metadata extraction.
* GET /api/pdf/{id}: retrieves a PDF file by ID.
* GET /api/pdf/{id}/metadata: retrieves the metadata for a PDF file by ID.
* POST /api/pdf/{id}/extract-metadata: extracts metadata from a PDF file by ID.

## Operations Runbook
To deploy the CloudStore E-commerce Portal, follow these steps:
* Initialize the Terraform configuration: `terraform init`
* Apply the Terraform configuration: `terraform apply`
* Configure the Load Balancer: set up the Load Balancer to distribute incoming traffic to the PDF File Handler.
* Configure the PDF File Handler: set up the PDF File Handler to handle PDF file uploads and send them to the PDF Processor.
* Configure the PDF Processor: set up the PDF Processor to extract metadata from PDF files and store it in the Database.
* Configure the Database: set up the Database to store the extracted metadata from PDF files.
